# MobPae Employee App

Frontend-only MVP for the MobPae employee app.

This app is consumer-facing. It covers employee onboarding, KYC status, salary advance eligibility, upcoming payroll recovery, request tracking, and the missing bank account add section.

## Scripts

- `npm run dev` - start the local frontend
- `npm run build` - typecheck and build
- `npm run preview` - preview production build
